# Git Agent — ИИ-агент для работы с Git через текстовые команды

Этот агент позволяет выполнять git-операции (создание веток, файлов, коммиты) с помощью команд на естественном языке.

## Быстрый старт

### 1. Настройка окружения

Создайте файл `.env` в корне проекта или установите переменные окружения:

```bash
# Для работы с GigaChat через токен
GIGACHAT_CREDENTIALS=ваш_токен
GIGACHAT_AUTH_URL=https://ngw.devices.sberbank.ru:9443/api/v2/oauth

# Или для mTLS
GIGACHAT_CERT_FILE=/path/to/cert.pem
GIGACHAT_KEY_FILE=/path/to/key.pem

# Список пользователей (через запятую)
AGENT_ALLOWED_USERS=ваш_user_id
```

### 2. Запуск агента

#### Интерактивный режим

```bash
# В текущем репозитории
python -m release_promotion_agent.cli.app git

# В указанном репозитории
python -m release_promotion_agent.cli.app git --repo /path/to/repo

# Режим сухой проверки (команды не выполняются)
python -m release_promotion_agent.cli.app git --dry-run
```

#### Одной командой

```bash
# Создать файл с содержимым
python -m release_promotion_agent.cli.app git run "создай файл 123.yaml с текстом Мяу"

# В конкретном репозитории
python -m release_promotion_agent.cli.app git run "создай файл test.txt с hello" --repo /path/to/repo

# Сухая проверка
python -m release_promotion_agent.cli.app git run "создай файл test.txt с hello" --dry-run
```

## Примеры команд

Вы можете писать команды на естественном русском языке:

### Создание файла в новой ветке
```
создай файл 123.yaml внутри которого написано слово "Мяу" 10 раз в ветку "123p"
```

Агент выполнит:
1. Создаст ветку `123p` (если нет)
2. Переключится на неё
3. Создаст файл `123.yaml` с содержимым "Мяу\nМяу\n..." (10 раз)
4. Добавит файл в git
5. Сделаем коммит

### Простые операции
```
переключись на ветку main
покажи статус репозитория
создай файл config.yaml с настройками базы данных
добавь все файлы и сделай коммит с сообщением "обновление конфигов"
```

### Специальные команды
В интерактивном режиме доступны специальные команды:
- `status` — показать статус репозитория
- `branch` — показать текущую ветку
- `exit` или `quit` — выход

## Как это работает

1. **Получение команды**: Вы вводите команду на естественном языке
2. **Обработка LLM**: GigaChat преобразует команду в последовательность git-операций в формате JSON
3. **Выполнение**: Агент выполняет команды по порядку:
   - Git-команды (`git checkout`, `git add`, `git commit`)
   - Создание файлов с указанным содержимым
4. **Результат**: Агент показывает пояснение и результат выполнения

## Формат ответа LLM

Агент ожидает от модели ответ в формате JSON:

```json
{
    "commands": [
        {"type": "git", "command": "git checkout -b feature"},
        {"type": "file", "path": "file.txt", "content": "содержимое"},
        {"type": "git", "command": "git add file.txt"},
        {"type": "git", "command": "git commit -m 'сообщение'"}
    ],
    "explanation": "пояснение что сделано"
}
```

## Безопасность

- **Dry-run режим**: Используйте `--dry-run` для предварительного просмотра команд
- **Только локальные операции**: Агент работает только с локальным репозиторием
- **Нет опасных операций**: Запрещены `force push`, `reset` и другие деструктивные команды
- **Логирование**: Все выполненные команды логируются

## Требования

- Python 3.11+
- Установленные зависимости: `pip install -e .`
- Настроенный GigaChat (токен или mTLS)
- Git установлен и настроен

## Отладка

Если агент не выполняет команды:

1. Проверьте конфигурацию:
   ```bash
   python -m release_promotion_agent.cli.app check-config
   ```

2. Используйте dry-run режим для просмотра команд

3. Проверьте логи ошибок LLM

## Ограничения

- Работает только с локальными репозиториями
- Требует подключения к GigaChat API
- Не выполняет push в удалённые репозитории
- Не делает merge/rebase между ветками
