# Architecture Decision Record (ADR)

## ADR-001

Использовать только GigaChat.

Причина:

Корпоративная политика запрещает использование сторонних LLM.

---

## ADR-002

Использовать langchain-gigachat.

Причина:

Официальная поддержка GigaChat в экосистеме LangChain и возможность дальнейшего использования LangGraph.

---

## ADR-003

Python 3.11+

Причина:

Рекомендованная версия для production, совместимость с pydantic>=2, langchain-gigachat и внутренними пакетами.

---

## ADR-004

Поддержка двух режимов аутентификации GigaChat (mTLS и token).

Причина:

Различные среды развёртывания требуют разных методов аутентификации.
mTLS подходит для production с инфраструктурой mutual TLS,
токен (credentials) — для тестов и сред без mTLS-инфраструктуры.

---
