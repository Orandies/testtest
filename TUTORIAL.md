# Полный туториал: Запуск ИИ-агента для Git-коммитов

Этот гайд поможет вам запустить агента с нуля, даже если у вас нет опыта.

## Шаг 1: Подготовка окружения

### 1.1 Проверьте Python
Откройте терминал (командную строку) и введите:
```bash
python --version
```
Должна быть версия 3.11 или выше. Если ниже — установите Python 3.11+ с официального сайта или через корпоративный портал.

### 1.2 Создайте виртуальное окружение (рекомендуется для безопасности)
В терминале перейдите в папку с проектом и выполните:

**Для Windows:**
```bash
cd путь\к\папке\release-promotion-agent
python -m venv venv
venv\Scripts\activate
```

**Для Linux/Mac:**
```bash
cd путь/к/папке/release-promotion-agent
python3 -m venv venv
source venv/bin/activate
```

> **Важно для Сбербанка:** Если у вас нет прав на создание venv, попробуйте установить пакеты в пользовательский режим (см. Шаг 2 с флагом `--user`).

## Шаг 2: Установка зависимостей

Установите все необходимые библиотеки:

```bash
pip install -r requirements.txt
```

**Если возникают ошибки с правами доступа (частая проблема в корпоративной среде):**
```bash
pip install --user -r requirements.txt
```

## Шаг 3: Настройка файла .env

1. Откройте файл `.env` в корне проекта (создан автоматически).
2. Заполните следующие поля:

```ini
# Обязательно: Ваш API ключ GigaChat
# Как получить:
# 1. Зайдите на https://developers.sber.ru/
# 2. Войдите под своей учётной записью Сбера
# 3. Создайте новый проект / приложение
# 4. Скопируйте API Key (или Client Secret)
GIGACHAT_API_KEY=ваш_ключ_здесь

# Необязательно: Путь к вашему локальному репозиторию
# Оставьте пустым, чтобы агент работал в текущей папке
LOCAL_GIT_REPO_PATH=

# Необязательно: Основная ветка (по умолчанию main)
DEFAULT_BRANCH=main
```

> **Важно:** Не отправляйте файл `.env` в GitHub! Он уже добавлен в `.gitignore`.

## Шаг 4: Подготовка вашего GitHub-репозитория

Так как агент работает с **локальной** копией, вам нужно клонировать ваш репозиторий:

1. Откройте терминал.
2. Перейдите в папку, где хотите хранить проекты (например, `C:\Projects` или `~/projects`).
3. Выполните команду:
   ```bash
   git clone https://github.com/ВАШ_НИК/ВАШ_РЕПОЗИТОРИЙ.git
   ```
4. Если требуется авторизация:
   - Используйте **Personal Access Token** вместо пароля (настройки GitHub -> Developer settings -> Personal access tokens).
   - Или настройте SSH-ключи, если в Сбере разрешено.

## Шаг 5: Первый запуск

### Вариант А: Интерактивный режим (чат с агентом)

Запустите агент, указав путь к вашему репозиторию:

```bash
# Активируйте venv, если создавали (см. Шаг 1.2)
# venv\Scripts\activate  (Windows)
# source venv/bin/activate (Linux/Mac)

python -m release_promotion_agent.cli.app git --repo-path "путь/к/вашему/репозиторию"
```

Если вы указали путь в `.env`, можно просто:
```bash
python -m release_promotion_agent.cli.app git
```

После запуска вы увидите приветствие. Введите команду текстом, например:
> "Создай ветку test-branch и файл hello.txt со словом Привет внутри"

Агент выполнит действия и покажет результат.

### Вариант Б: Одной командой (без чата)

Если хотите сразу выполнить задачу без входа в чат:

```bash
python -m release_promotion_agent.cli.app git --repo-path "путь/к/репо" --task "Создай файл 123.yaml со словом Мяу 10 раз в ветке 123p"
```

## Шаг 6: Отправка изменений в GitHub

Агент делает коммиты только в **локальную** копию. Чтобы изменения попали на GitHub:

1. После работы агента в терминале (в папке репозитория) выполните:
   ```bash
   git push origin <имя_ветки>
   ```
   Например: `git push origin 123p`

2. Если ветка новая, может потребоваться:
   ```bash
   git push --set-upstream origin <имя_ветки>
   ```

## Решение проблем в корпоративной сети (Сбербанк)

### Проблема: "No module named ..."
**Решение:** Установите пакет с флагом `--user`:
```bash
pip install --user typer requests gitpython
```

### Проблема: Нет доступа к интернету для pip
**Решение:**
- Попросите администратора добавить нужные пакеты во внутренний репозиторий.
- Или скачайте `.whl` файлы на домашнем ПК, перенесите на флешке и установите: `pip install package.whl`.

### Проблема: GigaChat не доступен
**Решение:**
- Убедитесь, что вы используете корпоративный VPN или прокси.
- Проверьте, что ваш API ключ действителен и имеет права на доступ.
- Попробуйте выполнить запрос через браузер с того же ноутбука, чтобы исключить блокировку сети.

### Проблема: Git не настроен
**Решение:**
Настройте имя и почту перед работой:
```bash
git config --global user.name "Ваше Имя"
git config --global user.email "ваша@почта.sberbank.ru"
```

## Пример полной сессии

1. **Запуск:**
   ```bash
   python -m release_promotion_agent.cli.app git --repo-path "C:/MyProjects/my-test-repo"
   ```

2. **Запрос агенту:**
   ```
   > Создай ветку feature-login и файл login.py с кодом print("Hello")
   ```

3. **Ответ агента:**
   ```
   ✅ Ветка 'feature-login' создана.
   ✅ Файл 'login.py' создан и закоммичен.
   ```

4. **Отправка в GitHub:**
   ```bash
   cd C:/MyProjects/my-test-repo
   git push --set-upstream origin feature-login
   ```

Готово! Теперь проверьте репозиторий на GitHub — там должна появиться новая ветка и файл.
